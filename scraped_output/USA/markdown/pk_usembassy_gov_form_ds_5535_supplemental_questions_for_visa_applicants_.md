## DS 5535 Submission Form
If your case is under administrative processing, please follow the instructions as mentioned in the 221(g) letter you received. Please only complete Form [DS-5535 Supplemental Questions for Visa Applicants](https://pk.usembassy.gov/wp-content/uploads/sites/76/ds5535-2.docx) (DOCX 66KB) if a visa officer has requested it. After you have downloaded and completed the DS-5535, you must submit it below. Please provide the requested information as soon as possible to avoid delays in your visa processing.
Visa Type
Immigrant Visa
Non Immigrant Visa
Surname:(Required)
Given Name:(Required)
Email:(Required)
Attach Word document(Required)
Accepted file types: doc, docx, Max. file size: 2 MB.
