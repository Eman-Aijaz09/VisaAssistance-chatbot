Welcome
You are staying in Pakistan only temporarily and need a travel document to return to Germany (for example: you lost your passport, it was stolen, etc.)
Please conduct the following steps:
Step 1: Pakistani Police
Report to the Pakistani police station in whose jurisdiction the passport loss has taken place. They will issue a first information report (so-called F.I.R.).
Step 2: German Embassy / Consulate General
Apply for a travel document to return to Germany (Rückreiseausweis). This passport substitute (Passersatzpapier) is valid for one month only and can usually be issued on the same day. The fee is 21,00 €.
Please submit the following documents:
| documents | additional information |
| application form | Download here |
| 3 passport photos | according to biometrical requirements (see explanation in the following downloads) Photos_Samples Passbildschablone |
| proof of your identitiy | - e.g. ID card, driving licence (i.e. documents with photos) |
| first information report | - so-called F.I.R.; issued by the Pakistani police - if issued in Urdu, please provide a translation into English or German |
| flight booking | - as a proof of your intended return to Germany |
Step 3: Pakistani Ministry of Interior
After the issuance of the travel document by the Embassy / Consulate General, you have to seek approval for a new Pakistani visa with the Pakistani Ministry of Interior:
| Ministry of Interior Address: Block R – Pak Secretariat, Islamabad Telephone: (0092 51) - 9207290 Opening hours: Mo - Fr 10:00 - 13:00h | Home Department, Govt. of Sindh Address: Barrack #71, Pak Secretariat, Karachi Telephone: (0092 21) - 99204920-21, 99211554 Opening hours: Mo - Fr 10:00 - 13:00h |
According to the Embassy's state of knowledge, the following documents need to be submitted there:
| F.I.R. in original |
| 3 passport photos |
| travel document to return to Germany issued by the Embassy / Consulate General |
4. Step: Pakistani Passport Office
To actually get the new visa stamped in your passport, the last step is to visit the following passport office:
